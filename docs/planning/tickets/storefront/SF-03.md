# SF-03 — One photography-led homepage story

**Phase:** 1. **Status:** Approved; awaiting dependencies and content gates. **Blocked by:** SF-01 and approved hero photograph/crop/copy/destination.  
**Outcome:** Arrival is one strong Bravos image followed by a clear shopping action.

## Scope and files

- Existing: `apps/storefront/app/page.tsx` composition.
- Proposed: `apps/storefront/app/components/home-hero.tsx`, `home-hero.module.css`, `apps/storefront/app/content/home-editorial.ts`, approved static files under `apps/storefront/public/editorial/`.
- Tests: focused home assertions in `tests/browser/storefront.spec.ts`.
- Content file contains presentation copy, media and existing destinations only; no price, stock or promotion logic.

## Acceptance criteria

- [ ] One lead story and one primary CTA beneath the image by default, with a brief Arabic caption; photography has no competing text overlay.
- [ ] Approved desktop/mobile crops preserve garment/model context. Approximately 70vh is an art-direction ceiling to test, not a forced height that hides the CTA on short phones.
- [ ] Hero links to an existing product or category query; no new route, fake seasonal campaign or unsupported claim.
- [ ] Reserve image dimensions; initial image loads promptly without waiting for animation/JS. Optional ≤400ms entrance respects reduced motion and does not postpone content.
- [ ] Search/category browsing remains reachable. Hero does not dominate filtered/search-result presentation.
- [ ] No carousel, autoplay video, countdown, equal-weight competing heroes or generic sale banner.
- [ ] Absent/invalid optional content yields an honest shop entry, but SF-03 is not accepted as a photography delivery until approved real imagery is demonstrated.

## Verification and risks

Typecheck; browse/search navigation browser checks; desktop and phone visual review including short-height device and slow image load. Main agent approves the photographic composition. Risk: current fixture imagery is unsuitable; content is a real gate, not a reason to fabricate a campaign. Coordinate `page.tsx` integration with SF-05.

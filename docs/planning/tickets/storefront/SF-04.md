# SF-04 — Discovery and optional campaigns

**Phase:** 1. **Status:** Approved. **Blocked by:** SF-02; integrate SF-03 when hero content is ready. Approved content is required only for optional modules actually displayed.  
**Outcome:** Customers move from the lead image through a small number of real stories into available catalog discovery.

## Scope and files

- Existing: `apps/storefront/app/page.tsx`.
- Extend proposed `app/content/home-editorial.ts`; add `app/components/campaign-chapter.tsx`, `editorial-island.tsx`, `home-sections.module.css`; reuse ShopWall/ProductCard.
- Approved static assets: `apps/storefront/public/editorial/`.
- Tests: homepage content-present/content-absent scenarios in `tests/browser/storefront.spec.ts`.

## Acceptance criteria

- [ ] Real catalog/category shop wall is the required delivery and remains strong without campaigns; no newest/best-selling labels unsupported by data. Missing stories never block this ticket or later purchase-confidence work.
- [ ] Render only approved modules with valid public destinations; at most 2–4 campaign modules and one editorial island. Zero optional modules is valid.
- [ ] Modules use media, short caption and clear shop link; closing content returns to existing commerce routes.
- [ ] Missing content, Hidden/deleted destinations and empty categories do not produce fake tiles or dead CTAs; omit invalid optional modules against current public data. Never create empty storytelling sections, reserved blank chapter space or placeholder campaigns.
- [ ] No invented brand heritage, guarantees, urgency or campaign claims; no News route/CMS added.
- [ ] Modules stack naturally on mobile, with meaningful heading hierarchy, restrained/no motion and stable images. No carousel overload or scroll-jacking.

## Verification and risks

Typecheck; homepage browse and links with optional content present/absent/invalid. Check actual copy/content with main agent. Risk: visual templates cannot substitute for photography/copy; preserve a complete shopping page when optional material is absent. Serialize home composition with SF-05; do not add API calls per card.

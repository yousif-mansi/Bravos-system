## What to build

Show manager operational reports with historical-cost profit and stock value. Deliver the complete staff/customer behavior below with the necessary persistence, business rules, API, usable Arabic UI and verification. The approved parent specification is authoritative.

## Acceptance criteria

- [ ] Manager dashboard provides current/day/calendar-month and branch/channel sales, purchases, expenses, best sellers, low stock, inventory value and merchandise/operating profit using Cairo dates. Staff cannot read private costs/profit/value.
- [ ] Include completed physical sales and Delivered online orders at final value; retain pending/confirmed order operations separately. Returns use actual authorized refund in processing period with original sale/channel link.
- [ ] Net merchandise sales subtract actual merchandise refunds; net cost reverses original/effectively corrected cost only for sellable returns; operating profit subtracts effective expenses.450 revenue,240 cost,280 refund,150 sellable cost restored yields 80 gross;20 expense yields 60 operating.
- [ ] Merchandise 450 plus customer delivery 50 shows final 500, with 450 merchandise-profit basis and no courier-margin/tax assumptions. Distinguish available from confirmed/in-transit value and visibly mark unresolved costs incomplete rather than zero.
- [ ] Verify period boundaries, branch/current-grant access, linked corrections, delayed sync, cost batches and retained discount attribution through HTTP, with usable Arabic manager report filters/details.
- [ ] Run the established typecheck, architecture, relevant behavior tests and build gates; preserve existing checks and record verification. No application test is considered passed merely because it is written.

# Triage labels

The five canonical triage roles use their default names in this repository.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | Waiting for information needed to proceed |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for agent implementation |
| `ready-for-human` | `ready-for-human` | Requires human implementation or judgment |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill names a role, use its corresponding GitHub label.

The separate category labels are `bug` and `enhancement`. A triaged issue carries one category and one state label, following the triage skill.

Edit the GitHub-label column if this repository adopts different state names later.

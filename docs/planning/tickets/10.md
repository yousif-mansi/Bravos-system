## What to build

Apply manager-configured coupons with atomic usage limits. Deliver the complete staff/customer behavior below with the necessary persistence, business rules, API, usable Arabic UI and verification. The approved parent specification is authoritative.

## Acceptance criteria

- [ ] Manager maintains codes, eligibility, dates, usage limits and combination settings. Cashier can apply/remove a code and see the permitted basket result but cannot manage rules.
- [ ] Apply eligible coupon after automatic offer and before employee deduction; preserve distinct effects and original accepted unit values. Enforce Cairo dates and configured combinations.
- [ ] Count use atomically at physical completion; expose the same public contract for later online confirmation. Repeated accepted operations consume once and changed payload identities fail.
- [ ] Test competing usage claims with real PostgreSQL concurrency, role permissions, invalid/expired codes, stacking and current rule changes. Public customer entry and cancellation release are extended in the online tickets.
- [ ] Run the established typecheck, architecture, relevant behavior tests and build gates; preserve existing checks and record verification. No application test is considered passed merely because it is written.

## Specification coverage

Stories: 110, 111, 112, 113. Acceptance scenarios: A08, A09, A10, A12, A34. Scenarios shared with later tickets are extended there; only the behavior in this ticket is its completion contract.

110. As the manager, I want to maintain coupon codes, eligibility, dates, usage limits and combination settings, so that offers and coupons can be controlled without a software release.
111. As a cashier or customer, I want to apply an eligible coupon to the current basket, so that its reduction is shown before cash-sale completion or order submission.
112. As a cashier or customer, I want the greatest-saving eligible automatic offer followed by the eligible coupon, so that configured reductions are applied consistently before any additional employee POS deduction.
113. As the manager, I want coupon usage recorded at POS completion or online confirmation and released once for cancelled undelivered orders, so that retries and cancellations do not corrupt usage limits.

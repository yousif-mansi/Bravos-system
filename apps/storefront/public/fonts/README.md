# Amiri editorial subset

`amiri-arabic-regular.woff2` is the Arabic Regular subset of Amiri, used only for storefront editorial headings. Commerce and body text use the existing Cairo font. The CSS uses `font-display: optional` and falls back to Cairo if the subset is unavailable or a glyph is outside its Unicode range.

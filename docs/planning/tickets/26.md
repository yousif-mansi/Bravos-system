## What to build

Download coherent password-protected business-data backups. Deliver the complete staff/customer behavior below with the necessary persistence, business rules, API, usable Arabic UI and verification. The approved parent specification is authoritative.

## Acceptance criteria

- [ ] Manager creates a password-protected data download saved outside the browser using maintained authenticated-encryption tooling, versioned manifest, counts and checksums.
- [ ] Consistently capture original/corrected records, batches/allocations, stable actor mappings, configuration and operation deduplication. Image references remain; image binaries are not required or falsely promised recoverable.
- [ ] Exclude active credentials/sessions/reset tokens/service secrets. Show known unsynchronized devices since central backup cannot include unsent local records. Creation is authorized server-side.
- [ ] Independently inspect/decrypt a scratch backup and verify record consistency, wrong-password/corruption detection, privacy and download usability without modifying live data.
- [ ] Run the established typecheck, architecture, relevant behavior tests and build gates; preserve existing checks and record verification. No application test is considered passed merely because it is written.

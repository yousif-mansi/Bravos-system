# Arabic report font

`Cairo-Regular.ttf` is Cairo Regular (400) from the Google Fonts Cairo family, taken from the npm package `@expo-google-fonts/cairo@0.4.2` (`400Regular/Cairo_400Regular.ttf`):

- Upstream project: https://github.com/Gue3bara/Cairo
- SHA-256: `44786A38E27C58262CBD65341BEDA4FA4F6C7085EC42E830B35BA1AE37807030`

Cairo replaced Noto Sans Arabic because `@react-pdf/renderer` misplaced Noto's Arabic dot marks and dropped some initial letters; Cairo renders the same report text correctly in both Poppler and PDFium.

The font is distributed under the SIL Open Font License 1.1. The retained license text is `OFL.txt` in this directory.

# PART 2 — Patterns to Steal (and Reject)

## Hero

| Pattern | Source | Verdict for Bravos |
| --- | --- | --- |
| CTA under image (~70vh), not overlaid | ARKET | **Steal** — protects photography |
| Hero with zero text/CTA (one beat) | Bottega | **Steal sparingly** — opening statement only |
| 50/50 split magazine hero | Acne | Optional for campaign modules |
| Equal multi-hero homepage | Apple (anti) / generic ecom | **Reject** — one lead story |
| Countdown / scarcity overlay | FOG-adjacent culture | **Reject** without real drop ops + photo budget |

**Bravos hero rule:** Photography owns the frame. Chroma lives in the image. UI is bone, ink, and restraint. One primary CTA under the hero — tracked uppercase, hard edge, no gradient button candy.

## Product Discovery

| Pattern | Source | Verdict |
| --- | --- | --- |
| Gutterless shop wall | LOEWE | **Steal** |
| 4-col zero-gutter grid | Acne | **Steal** for collection density |
| Editorial captions on tiles | Our Legacy | **Steal** — short, not essays |

| Weak filters / silent bag | SSENSE critique | **Reject** |
| Aggregator density | Mr Porter multi-brand | **Reject** for single-brand Bravos |

**Bravos discovery rule:** Wall first, filters honest. Visible filter chips. Bag feedback that is felt (HUD / micro-confirmation), never whispered into oblivion.

## Product Page (PDP)

| Pattern | Source | Verdict |
| --- | --- | --- |
| Persistent right rail (size/color/material) | LOEWE / Work & Co | **#1 steal** |
| Chaptered desire → specs | Apple | **Steal** |

**Bravos PDP rule:** Image theater left (or main), commerce rail always present. Chapters below: Fit, Fabric, Care, Style with. Price visible. Size guidance confident, not apologetic.

| Pattern | Source | Verdict |
| --- | --- | --- |
| Chrome recession; progress clarity | Acne speed ethos + best-in-class checkout craft | **Steal calm** |

# PART 3 — Bravos Store Concept

## Visual personality

**Line:** *Tailored restraint with pulse.*

- **Canvas:** Warm bone / off-white (Our Legacy `#FFFFFC` family — tune to brand bone, not pure `#FFF`)
- **Ink:** Near-black warm (`#121110` family) — never pure cool black on bone
- **Chroma:** Reserved for photography and rare status — not UI chrome
- **Edges:** Hard, 0–2px radius. Square confidence (Mr Porter), not soft SaaS pills
- **Type:** Display (serif or custom display) for brand moments + tracked uppercase commerce gothic/sans for labels, prices, CTAs
- **Density:** Acne’s zero-chrome ambition with LOEWE’s gallery walls — rich image, poor UI furniture

## Emotional response we want

1. **Arrival** — “I am somewhere considered.” (Bottega silence beat + ALD warmth)  
2. **Desire** — garment before rationale (Apple)  
3. **Confidence** — decisions feel guided, not gamed (visible price, honest stock, clear size)  
4. **Pace** — browsing feels like a well-edited magazine, not a feed (FOG chapters, Saint Laurent islands)  
5. **Exit pride** — checkout calm enough that premium perception survives payment

## Browsing philosophy

- **Shop walls over card grids.** Products abut; gutters are a chrome tax.  
- **Campaign chapters over infinite scroll catalogs.** Seasonal narrative modules that route into walls.  
- **Filters as lens, always visible.** Never SSENSE-silent.  
- **Editorial side-doors** (News / Stories / Runway-analog) deepen brand but never replace commerce clarity.  
- **Mobile = same philosophy, compressed** — sticky commerce, not a different brand.

## Storytelling model

| Layer | Role | Cadence |
| --- | --- | --- |
| **Hero silence or under-CTA** | Claim the eye | Seasonal / campaign |
| **Campaign chapters** | World-build, then shop | Modular templates (LOEWE/FOG) |
| **Shop walls** | Desire at scale | Always on |
| **PDP chapters** | Desire → decision → care | Per product |
| **Captions** | Voice — short, masculine, precise | Everywhere images need a human line |

**Voice:** Confident, brief, tailored. No lifestyle essay on a sock PDP. No scarcity theater.

# PART 4 — Internal System UX Research

*Synthesized from `/workspace/research/bravos-admin-ux-gap-analysis.md` (23 Sep 2026). Full dossiers and URLs live there; this part extracts what matters for Bravos retail ops.*

## Thesis

> **World-class operational products optimize for decision speed and calm under load.  
> Normal admin panels optimize for feature completeness and schema coverage.**

Bravos already has backend, business logic, retail workflows, and an internal design system. The experience gap — if any — will not be “more features.” It will be whether operators can decide faster, with less visual noise, under floor pressure.

## What “world-class” looks like (dimensions)

| Dimension | Normal admin | World-class ops product |
| --- | --- | --- |
| Purpose | CRUD for every entity | Accelerate operator jobs under time pressure |
| Home | Widget soup / equal KPIs | 3–5 action-driving metrics + “needs attention” |
| Navigation | Mirrors DB schema | Job-labeled, frequency-ordered, ≤2 nest levels |
| Density | Sparse pretty cards or cramped clutter | High density via alignment; chrome recedes |
| Tables | Flat grids, weak filters | Search + facets + chips + bulk + inline status |
| Forms | Long pages, late validation | Progressive disclosure, consequence-aware copy |
| Empty states | “No data” | Teach + path to first action; zeros keep layout |
| Feedback | Generic toasts / silence | Specific: what happened + what to do next |
| Speed | Mouse-only | Keyboard paths, ⌘K, HUD confirmations |
| Trust | Decorative color | Color reserved for status; type carries hierarchy |
| Ops safety | Destructive one click away | Disclose by risk; confirm scope; audit trails |

## Reference systems (steal map for Bravos admin)

| System | Why it matters | Steal |
| --- | --- | --- |
| **Shopify Admin / POS** | Closest retail analog | Resource index pattern; empty→create; collapsible chrome; POS smart-grid frequency placement ([shopify.dev](https://shopify.dev/docs/api/app-home/patterns/templates/resource-index), [POS UI](https://shopify.dev/docs/apps/build/pos)) |
| **Linear** | Dense calm work software | Chrome recedes; density through craft; same object, many views ([linear.app/now](https://linear.app/now/behind-the-latest-design-refresh)) |
| **Stripe Dashboard** | High-stakes money ops | Opinionated Home (~5 metrics + compare); job IA; microcopy as trust ([925 Studios](https://www.925studios.co/blog/stripe-dashboard-design-breakdown)) |
| **Vercel** | Ops monitoring | Curated signal feeds; filter pills always visible; audit log first-class ([vercel.com/blog](https://vercel.com/blog/security-through-design-creating-the-improved-firewall-experience)) |
| **Notion** | Power-user IA | Favorites / collapse / breadcrumbs for multi-store graphs |
| **Attio** | Design-first B2B | Progressive disclosure; one object language everywhere |
| **Raycast** | Speed & HUD | Command palette; discoverable shortcuts; non-blocking confirmations |
| **Apple Business Manager** | Multi-unit admin | Role + OU scoping as UX, not just ACL |

## Cross-cutting principles (admin)

1. **Actions over archives** — Design for the next decision, not the full schema.  
2. **Calm density** — More data, less chrome weight.  
3. **Jobs not tables** — Nav speaks operator language (Orders, Inventory, Staff, Registers, Exceptions).  
4. **Show the lens** — Active filter chips always visible.  
5. **Specificity builds trust** — Every error/status: what + next step.  
6. **Disclose by frequency and risk** — Common/safe visible; rare/dangerous gated.  
7. **Empty is a feature** — Teach, route, or celebrate — never dead-end.  
8. **One system** — Shared components so modules don’t Frankenstein.  
9. **Speed is UX** — Instant search, keyboard paths, non-blocking HUDs.  
10. **Opinionated overview, flexible drill-down** — Home curates; reports explore.

## Empty-state cheat sheet (retail ops)

| Context | Pattern | Tone |
| --- | --- | --- |
| First-use collection | Headline + “X will appear here” + primary create | Neutral / encouraging |
| Search no hits | Text-only | **Neutral only** |
| Filters no hits | Text + chips still visible | Neutral |
| Dashboard no volume | Zeros + axes + structure preserved | Neutral |
| Inbox caught up | Optional celebration | OK to celebrate |

Source taxonomy: [Northbase empty states](https://www.northbase.design/patterns/empty-states) + Shopify / Stripe patterns.

# PART 5 — Gap Analysis (Provisional)

> **IMPORTANT — Label: PROVISIONAL**  
> No Bravos storefront or admin screenshots were available for this engagement.  
> This section is an **audit framework + provisional gap hypotheses** for a brand that has completed design system + retail workflows but has **not yet reached experience excellence**.  
> It does **not** invent specific current UI flaws. Score against live screens when they arrive.

## 5.1 Premise

Given: backend, business logic, retail workflows, and internal design system are done.  
Therefore: gaps will cluster in **craft, perception, decision speed, and consistency of application** — not in missing entities or missing CRUD.

## 5.2 Provisional gap themes (hypotheses to validate)

These are the *usual* failure modes when systems exist but experience excellence does not. Treat as interview questions for the product — not as findings.

| Theme | Storefront hypothesis | Admin hypothesis |
| --- | --- | --- |
| **Chrome vs content** | UI furniture may still compete with photography | Chrome may be as bright as work content (pre-Linear) |
| **Type system underuse** | Display + commerce pairing may not yet be enforced end-to-end | Hierarchy may rely on color/weight noise instead of type |
| **Hero / PDP craft** | Hero CTA overlays or equal-hero homepage; PDP may lack persistent commerce rail | N/A |
| **Discovery honesty** | Filters or bag feedback may be soft / silent | Filter chips may hide active constraints |
| **Motion discipline** | Either none or scroll-jack | Toasts may block; no HUD confirmations |
| **Home opinion** | N/A | Home may still be metric soup vs 3–5 action KPIs + needs-attention |
| **Object consistency** | Product tile ≠ PDP ≠ cart visual language | Same order may look different in search / list / detail / modal |
| **Risk disclosure** | Checkout errors vague | Refunds / voids / stock adjusts may lack consequence copy |
| **Role / scope** | N/A | Store vs region vs HQ Home may be identical |
| **Performance as brand** | Image weight / CLS may tax premium feel | Perceived latency on search/tables |

## 5.3 Checklist — what to look for when screens arrive

### Storefront audit checklist

**Homepage / hero**
- [ ] Is there a single lead story, or equal-hero soup?
- [ ] Does photography own the frame? Is CTA under image or overlaid?
- [ ] Is there at least one seasonal “silence” or understated hero beat?
- [ ] Warm bone canvas vs cool gray / pure white?
- [ ] Chroma only in photography (UI monochrome)?

**Discovery / PLP**
- [ ] Gutterless or near-gutterless shop wall?
- [ ] Filter chips visible when active?
- [ ] Tile captions short and editorial?
- [ ] Bag/add feedback perceptible within ~100–200ms perception?
- [ ] Hard edges 0–2px; no soft SaaS card language?

**PDP**
- [ ] Persistent commerce rail (desktop) / sticky commerce bar (mobile)?
- [ ] Garment large before fabric/spec tables?
- [ ] Chaptered sections (Fit / Fabric / Care / Style)?
- [ ] Price always visible?
- [ ] Size/stock guidance specific?

**Checkout**
- [ ] Visual quiet relative to brand pages?
- [ ] Errors: what happened + next step?
- [ ] No campaign motion; no surprise upsell walls?

**Motion / photo**
- [ ] Motion only on key moments (enter, swap, add, rail)?
- [ ] No scroll-jack?
- [ ] Campaign photography quality matches premium claim?

**Type**
- [ ] Display + commerce dual system used consistently?
- [ ] Tracked uppercase for labels/CTAs?
- [ ] Square corners throughout commerce UI?

### Admin audit checklist

Score each 0–2 (missing / partial / strong). From admin research §5:

**Home & KPIs**
- [ ] ≤5 action KPIs with targets/comparisons  
- [ ] “Needs attention” queue (exceptions, offline POS, stockouts, cash variance)  
- [ ] Role-specific Home (store vs region vs HQ)  
- [ ] Dashboard-zero preserves layout  

**Navigation & findability**
- [ ] Job-based IA; ≤2 levels; frequency ordered  
- [ ] Global search across orders / SKUs / staff / stores  
- [ ] Favorites / Recents / store switcher  
- [ ] Collapsible nav for dense tables  
- [ ] Command palette for power users  

**Operational tables**
- [ ] Consistent index pattern (identity, status badge, bulk, pagination)  
- [ ] Filter chips always visible  
- [ ] Saved views per role  
- [ ] Row inspect without losing list context  

**POS / floor adjacency**
- [ ] High-frequency actions exposed (smart-grid logic)  
- [ ] Admin ↔ POS language consistent  
- [ ] Touch-safe patterns for floor-facing views  

**Forms & risk**
- [ ] Progressive disclosure on create vs adjust  
- [ ] Refunds / voids / stock adjusts: consequence copy + confirm scope + audit  
- [ ] Inline validation with repair instructions  

**Trust & system quality**
- [ ] Status color reserved (success / warn / critical)  
- [ ] Chrome quieter than content  
- [ ] One object model visually across surfaces  
- [ ] Audit log findable  
- [ ] Empty states correct by context type  

## 5.4 Recommended validation sequence (when screens land)

1. Score storefront checklist in a 90-minute war-room with design + brand.  
2. Score admin checklist with 2–3 real operators (store + HQ).  
3. Map top 10 operator jobs; watch for hesitation, tab sprawl, re-entry.  
4. Prioritize gaps that block **premium perception** (storefront) and **decision speed / exception handling** (admin) before decorative polish.  
5. Migrate to shared patterns (shop wall + PDP rail; resource index + filter chips) rather than one-off screen fixes.

**Admin inspirations (internal):** Shopify Admin/POS, Linear, Stripe Dashboard, Vercel observability UX, Raycast command speed, Attio object consistency — see Part 4.

## 2. Design Principles

### Storefront principles

1. **Photography is the chroma.** UI stays bone + ink. If the interface is colorful, the brand is leaking.  
2. **Tailored restraint with pulse.** Quiet surfaces, decisive moments — not quiet-luxury muteness, not streetwear noise.  
3. **Hard edges, hard decisions.** 0–2px radii; visible prices; honest stock; no soft SaaS melting.  
4. **Dual type, single voice.** Display for brand; tracked commerce type for action. Never one font doing both badly.  
5. **Walls over cards.** Products abut; gutters are chrome.  
6. **Rail always present.** Size / color / material never require a pilgrimage back up the page.  
7. **Desire before specs.** Chapters earn the table.  
8. **Motion is punctuation.** Brief, confident, rare.  
9. **Checkout is operational.** Brand calm, not brand theater.  
10. **Speed is prestige.** Acne proved it — latency taxes luxury.

### Internal product principles

1. **Decision speed + calm under load** over feature completeness.  
2. **Jobs not tables** in IA and labels.  
3. **Opinionated Home** (3–5 KPIs + needs attention); flexible reports.  
4. **Show the lens** — filter chips always visible.  
5. **Disclose by frequency and risk.**  
6. **Specificity builds trust** — what happened + next step.  
7. **One object language** across search, list, detail, modal.  
8. **Chrome recedes** (Linear); content and exceptions dominate.  
9. **Empty is a feature** — teach, route, or celebrate.  
10. **Keyboard + HUD** for power operators (Raycast literacy).

## 3. Storefront Direction

### Positioning

Bravos is a **premium men’s fashion destination** — not a marketplace, not a drop cult, not a quiet-luxury museum gift shop. The site should feel like entering a tailored room with a pulse: warm bone underfoot, campaign light on the walls, commerce that never apologizes.

### Visual system (experience layer)

| Token | Direction |
| --- | --- |
| Canvas | Warm bone / off-white (Our Legacy family) |
| Ink | Warm near-black |
| Accent in UI | None by default; status only where required |
| Radius | 0–2px |
| Grid | Near zero-gutter shop walls; magazine islands for campaigns |
| Type | Display + tracked uppercase commerce |
| Elevation | Flat — shadow is not luxury here |
| Iconography | Minimal; labels carry meaning |

### Homepage architecture

1. **Optional silence beat** (Bottega) or **ARKET under-CTA hero** — one lead story.  
2. **Campaign chapters** (FOG / LOEWE modular) — 2–4 shoppable modules max per season.  
3. **Shop wall** — featured category or new arrivals, gutterless.  
4. **Editorial island** — News / story (Acne / SSENSE grammar), one only.  
5. **Closing wall or look** — route back to commerce.

Reject: equal-hero carousels, countdown scarcity, widget dashboards, autoplay video walls that mute on mobile.

### Collection / discovery

- Gutterless or 4-col zero-gutter (Acne) on desktop; 2-col on mobile with same edge language.  
- Short captions (Our Legacy).  
- Facets + **visible chips** + clear all (fix SSENSE’s sin).  
- Sort secondary to filtering; don’t hide merchandising logic.

### PDP

- **LOEWE rail:** imagery primary; sticky right rail for size / color / material / CTA.  
- **Apple chapters** below fold: Fit → Fabric → Care → Style with.  
- Garment large before any table.  
- Price always on.  
- Mobile: sticky bottom commerce bar; chapters stack.

### Checkout

- Same type + bone canvas; motion off; chrome thinner.  
- One quiet complete-the-look suggestion max.  
- Error copy at Stripe specificity.  
- Progress clear; no magazine chrome.

### Mobile

Same philosophy compressed — not a separate “app-like” brand. Thumb-reach for commerce. Hero discipline holds. Campaign chapters swipe or stack without becoming a TikTok feed.

## 4. Internal Product Direction

### North star

Operators should feel **faster and calmer** after the experience pass — not impressed by new widgets. World-class = decision speed + calm under load.

### Home

- **≤5 action KPIs** with period compare / target delta (Stripe model): e.g. sales vs plan, stockouts, open exceptions, cash variance, staffed vs scheduled.  
- **Needs attention rail:** refunds, voids, low stock, POS offline, compliance holds (Vercel alerts pattern).  
- **Role-aware:** store manager ≠ regional ≠ HQ depth (Apple Business Manager scoping mindset).  
- **Dashboard-zero:** keep layout with zeros — never replace Home with a poster.

### Navigation

- Job labels: Orders, Inventory, Staff, Registers, Exceptions — frequency ordered, ≤7 top level, ≤2 nest.  
- Collapsible / icon-rail for dense table work (Shopify 2026, Linear).  
- Favorites / Recents / store switcher (Notion + Linear).  
- Global search + **command palette** for jump-to order / SKU / staff / store (Raycast).  
- Settings / Audit / Help pinned bottom.

### Tables (resource index as default)

Unify on Shopify-like index: primary identity column + status badge + numerics right-aligned + selection/bulk + pagination + filter chips. Row → side panel / split for inspect without losing list (Linear / Vercel). Saved views per role (“Today’s exceptions”).

### Forms & risk

Progressive disclosure. Create vs adjust are different friction. Refunds / voids / stock adjusts: consequence copy + confirm scope + audit trail. Inline validation with repair instructions. Preserve input on failed submit.

### POS adjacency

High-frequency floor actions on a smart-grid mental model (Shopify POS) — not buried in settings. Admin and POS share language and component system. Touch-safe hit targets on any floor-facing view.

### Visual quiet

Status color reserved. Chrome quieter than content. One object model. Continuous pruning of icon inflation and border noise (Linear’s discipline).

## 7. Motion Recommendations

**Philosophy:** Motion is punctuation, not personality. Premium men’s fashion does not bounce.

### Principles

1. **Key moments only** — hero enter, image swap, rail update, add-to-bag, chapter reveal, admin HUD.  
2. **Duration** — 150–400ms for UI; ≤600ms for hero settle. No multi-second scroll theater.  
3. **Easing** — Decelerate / standard ease-out; no elastic, no bounce.  
4. **Reduced motion** — Honor `prefers-reduced-motion`; instant state swap.  
5. **No scroll-jack** — Drop Edition’s lesson in the negative. User owns the scroll.  
6. **Checkout = 0 campaign motion.**  
7. **Admin motion** — Prefer opacity/position microfeedback; never delay table paint.

### Suggested choreography map

| Surface | Motion | Notes |
| --- | --- | --- |
| Hero | Fade + 1–2% scale settle | Once per landing |
| Shop wall | Stagger ≤3 items on first paint only | Don’t re-stagger on filter |
| PDP image swap | Crossfade ≤250ms | Tied to swatch |
| Rail / sticky bar | Slide/fade presence | Not continuous parallax |
| Add to bag | Scale pulse on bag icon + HUD | Felt confirmation |
| Campaign chapter | Optional horizontal snap | Optional — kill if it costs CLS |
| Admin toast → HUD | Non-blocking, auto-dismiss | Replace modal success |

Tooling: GSAP or equivalent fine for branded moments; CSS transitions for system UI. Measure CLS / INP — Acne’s conversion story is partly speed.

## 8. Photography Recommendations

Photography is Bravos’s chroma budget. Treat it as product, not decoration.

### Direction

| Axis | Recommendation |
| --- | --- |
| **Temperature** | Warm filmic (ALD) on lifestyle/campaign; controlled studio for PDP hero garment |
| **Canvas relationship** | Images must sit on bone without fighting — grade toward warm neutrals |
| **Crop** | Generous, object-forward (LOEWE); avoid tiny centered product on infinite gray |
| **Hero** | One courageous silent or under-CTA frame per campaign; production quality non-negotiable |
| **PDP** | Large garment first; then detail / fabric / on-body; secondary angles for hover/swap |
| **Shop wall** | Consistent ratio per wall; mixed ratios only in editorial islands |
| **Mobile** | Shoot with vertical crop in mind; don’t letterbox campaign stills into postage stamps |
| **Retouch** | Restraint — fabric truth over beauty blur; men’s premium reads as honest material |

### What not to do

- Scarcity / drop photography language without budget (FOG don’t-copy).  
- Cold Scandi emptiness (Our Legacy don’t-copy for DTC newcomers).  
- Half-retro nostalgia sets (ALD don’t-copy).  
- Stock-gray ghost mannequins that scream commodity marketplace.  
- Text baked into photos that fights the type system.

### Production cadence

Modular campaign templates (LOEWE/FOG) only work if photography is planned as modules: hero silence plate, chapter plates, wall set, PDP set. Brief photographers for **template slots**, not random assets.

Phased for experience excellence — no backend work, no unnecessary features. Sequence by perception leverage and operator pain.

## Closing thesis

Bravos does not need more product. It needs **tighter taste**.

On the storefront: warm bone, hard edges, dual type, photography as chroma, LOEWE’s commerce rail, campaign chapters with FOG’s shoppable worlds, Apple’s chaptered desire, Acne’s speed, Bottega’s one silent breath — tailored restraint with pulse.

On the internal product: Shopify’s resource index discipline, Stripe’s opinionated Home, Linear’s quiet density, Vercel’s visible lens, Raycast’s speed — decision speed and calm under load.

When screens arrive, score Part 5 honestly. Then execute the roadmap in order. Experience excellence is a sequence of removals and a few precise additions — not a new feature catalog.

# Storefront evolution — execution design brief

29 September 2026. Local storefront presentation work follows the user's current dark fashion direction and preserves the completed Phase 1 operational changes. No commit, push or deployment is implied.

- Obsidian canvas, layered charcoal surfaces, ivory text and restrained champagne accents. Official ivory logo assets remain the identity source.
- Homepage separates an oversized English display title and short Arabic heading from the existing cover image. The full reserved cover ratio retains its baked branding; the shopping action sits below the image.
- Collections link to actual API categories. The existing real product wall, filters and sorting remain the commerce destination. No invented campaigns, best-seller claims or placeholder catalog facts.
- A separate brand introduction explains the real process: select an actual size/color pair, review delivery and total, then submit a pending COD request for WhatsApp confirmation.
- Arabic headings center on phones while forms retain RTL reading and interaction order. Section spacing and borders distinguish the journey; motion stays CSS-only and respects reduced motion. Loading has no artificial delay.
- The user confirmed embedding permission for both uploaded font families. Local Androgy Demo provides English display; Thmanyah Sans 400/500/700 provides commerce and metadata; Thmanyah Serif Display 400/700 provides editorial Arabic. Minimal originals are copied without conversion; no storefront Google font dependency remains.
- Cart persistence, variant eligibility, branch fulfillment, quote validation, analytics, order replay and uncertain-submission recovery remain owned by their existing features. Dark presentation must preserve focus, meaningful disabled states and 44px actions.

Verification runs against an isolated development database. Emulated responsive checks do not establish physical-device or hosted-production readiness. Real garment photography and production delivery configuration remain launch inputs.

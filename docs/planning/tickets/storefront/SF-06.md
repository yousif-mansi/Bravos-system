## Acceptance criteria

- [x] Large garment imagery precedes detailed specifications, while product name, availability and existing buying control remain clear.
- [x] Gallery uses only actual `imageRefs` in catalog order, with thumbnails/previous-next controls when multiple images exist. Single/no-image cases are complete and stable.
- [x] No inferred variant-specific image, fabricated angle or caption. Images remain product-level unless the contract actually changes in a separately approved project.
- [x] Gallery navigation works by keyboard and touch with labeled controls, current-image indication and useful alt text; no hover-only access or autoplay.
- [x] Initial image is prioritized; later images are deferred without shifting the layout. Direct catalog URL/revocation remains intact.
- [x] Hidden/missing product still resolves to existing not-found flow. Coming Soon and Out of Stock detail pages remain browsable with their existing disabled buying rules.
- [x] No zoom/lightbox library required; add no gesture-only interaction or unnecessary gallery feature.

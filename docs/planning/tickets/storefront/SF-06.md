# SF-06 — Product gallery and desire-first hierarchy

**Phase:** 3. **Status:** Approved; awaiting dependencies and content gates. **Blocked by:** SF-02.  
**Outcome:** Product photography leads the page, with all existing purchase information reachable and a usable gallery.

## Scope and files

- Existing: `apps/storefront/app/products/[productId]/page.tsx`.
- Proposed beside it: `product-gallery.tsx`, `product-page.module.css`; reuse ProductMedia.
- Tests: `tests/browser/storefront.spec.ts`, `tests/browser/catalog-media.spec.ts`.
- Keep purchase panel's current state/behavior intact for SF-07; preserve server detail fetch and notFound behavior.

## Acceptance criteria

- [ ] Large garment imagery precedes detailed specifications, while product name, availability and existing buying control remain clear.
- [ ] Gallery uses only actual `imageRefs` in catalog order, with thumbnails/previous-next controls when multiple images exist. Single/no-image cases are complete and stable.
- [ ] No inferred variant-specific image, fabricated angle or caption. Images remain product-level unless the contract actually changes in a separately approved project.
- [ ] Gallery navigation works by keyboard and touch with labeled controls, current-image indication and useful alt text; no hover-only access or autoplay.
- [ ] Initial image is prioritized; later images are deferred without shifting the layout. Direct catalog URL/revocation remains intact.
- [ ] Hidden/missing product still resolves to existing not-found flow. Coming Soon and Out of Stock detail pages remain browsable with their existing disabled buying rules.
- [ ] No zoom/lightbox library required; add no gesture-only interaction or unnecessary gallery feature.

## Verification and risks

Typecheck; gallery cases and existing catalog-media/storefront browser regressions; phone/desktop screenshots and keyboard pass. Risk: visually replacing the current grid must not eager-load all full-size images or expose Hidden media through a cache. Real garment images are needed for final art-direction acceptance.

# Print connector assets

`Cairo-Regular.ttf` is the trusted Cairo face. `Cairo-OFL.txt` is its SIL Open Font License. The native helper loads this font file for label and receipt text.

`bravos-receipt-logo.png` is a derived raster of the official vertical mark and BRAVOS wordmark from `logo svg/01_Primary-Logo_Vertical_Black.svg`. Do not invent a replacement mark.

## What to build

Manage product media and publication with a safe public catalog. Deliver the complete staff/customer behavior below with the necessary persistence, business rules, API, usable Arabic UI and verification. The approved parent specification is authoritative.

## Acceptance criteria

- [ ] Manager maintains product images through a storage adapter and optional size guide; validate uploads and preserve references. Local storage works without hosting purchase.
- [ ] Available products with zero sellable variants remain browsable and show Out of Stock, with ordering disabled; stocked variants remain selectable when siblings are empty. Coming Soon is a public nonorderable preview; Hidden is excluded.
- [ ] Public catalog responses contain only customer-safe fields and latest synchronized central availability. No cost, profit, staff/session/order data or privileged modules leak through direct APIs, errors or images.
- [ ] Test status transitions/restocking and role-safe responses via HTTP plus manager media/public-product UI checks. POS visibility rules remain unchanged.
- [ ] Run the established typecheck, architecture, relevant behavior tests and build gates; preserve existing checks and record verification. No application test is considered passed merely because it is written.
